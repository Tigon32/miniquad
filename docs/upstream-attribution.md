# Original Miniquad source and contributors

This project began as a fork of [Miniquad](https://github.com/not-fl3/miniquad).
The original project is a Rust graphics, input, and window library.

**Original project:** [not-fl3/miniquad](https://github.com/not-fl3/miniquad)  
**Original author:** Fedor Logachev (not-fl3)  
**Current fork:** [Tigon32/miniquad](https://github.com/Tigon32/miniquad)

See [LICENSE-MIT](../LICENSE-MIT) and [LICENSE-APACHE](../LICENSE-APACHE).
These licence files remain part of this source tree.
Other contributions can have their own copyright or licence notices.
Keep those notices when you reuse the files.

This fork contains additional browser work, tests, agent guidance, and architecture decisions.
The proposed roadmap includes voxel rendering and optional server-side simulation.
Those features are not yet a supported part of the library.

The new project name has not been selected.
A new name will not remove the original project credit.
A rename does not mean that the original maintainers endorse the fork.
